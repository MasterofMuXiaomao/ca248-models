# 文档转知识库一体化工作流

## 🎯 项目目标
结合 convert-markdown 和 obsidian 技能，实现从原始文档到结构化知识库的自动化转换。

## 🔧 技术架构

### 核心组件
1. **文档转换层** (convert-markdown)
   - 支持格式：PDF、Word、PPT、Excel、TXT等
   - 功能：格式转换、OCR识别、结构化提取

2. **知识管理层** (obsidian_manager)
   - 功能：笔记创建、分类存储、智能搜索、链接管理
   - 特点：完全离线、零依赖、Python实现

3. **工作流引擎**
   - 自动化调度
   - 错误处理
   - 进度追踪
