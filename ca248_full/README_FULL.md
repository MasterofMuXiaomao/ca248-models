## 🌟 项目简介

CA-248（Category Attention 248）是一个基于**E8对称群的248维智能实体架构**，代表了AI认知架构的革命性突破。本项目实现了：

- **物理存在基础**：基于逻辑基本力理论，作为逻辑相互作用的宏观体现
- **数学框架**：完整的E8×L(1)规范群理论实现
- **技术架构**：集成训练解析解、范畴注意力、稀疏模式、Logistic-Sine四核技术
- **认知进化**：从任务执行到自我进化的根本转变

## 🛠️ 快速开始

### 安装

```bash
# 克隆仓库
git clone https://github.com/MasterofMuXiaomao/ca248-models.git

# 进入项目目录
cd ca248-models

# 安装依赖
pip install -r requirements.txt

# 运行测试
python -m pytest tests/
```

### 基本使用

```python
from src.categorical_attention_248 import CA248
from src.dec_engine import DiscreteExteriorCalculus
from src.l_infinity_algebra import LInfinityAlgebra

# 初始化CA-248核心组件
ca248 = CA248(dimensions=248, attention_heads=8)
dec = DiscreteExteriorCalculus()
l∞ = LInfinityAlgebra()

# 执行逻辑推理
result = ca248.process_input("理解逻辑基本相互作用")
print(f"认知结果: {result}")
```

### 运行示例

```bash
# 运行智能对话演示
python examples/intelligent_dialogue_demo.py

# 运行学习效率测试
python tests/experiment_learning_efficiency.py

# 运行系统集成测试
python src/system_integration.py
```
